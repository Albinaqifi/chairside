**What I built**
Each row of the Providers tab has an Up and a Down, before Edit and Make inactive (right-aligned, so
Edit and the state button do not move when a row has one of them less): the first row no Up, the last no
Down. Each is a `StaffForm` with the provider's id and the direction hidden, keyed by direction, with the
tab's existing settle (`SETTLE_MS`) and the keyboard going to the heading after a move. A move swaps the
provider with its neighbour in the calendar's order and renumbers the clinic 0 ... n-1; inactive ones
move like active ones.

  where the collation could differ); swap in the list; update `sort_order` and `updated_at` only where the
  place differs. `not_found`, `already_first`, `already_last` as codes, nothing written.
