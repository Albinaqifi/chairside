- **A button's or input's own URL.** A `formAction` is classified as a form's `action` is, except
  that a possibly missing value passes (the form is then checked on its own). A URL needs
  `formMethod="post"` on the same element: lint cannot see the form around a button.
- **Spreads onto `<button>` and `<input>`: refused by type.** A spread is reported when its type
  could carry `formAction` or `formMethod`: a property of either name, an index signature, `any`,
  `unknown`. **This is the choice the owner should look at:** E00-T04's button and input components
  then type their props as `Omit<ComponentProps<'button'>, 'formAction' | 'formMethod'>` (and
  write a function-only `formAction` out when they need one), and TypeScript stops callers from
  passing a URL. Rejected: refusing every spread (E00-T04 would list every prop by hand); checking
  the props' types instead of their presence (more code, nobody needs it yet); only naming spreads
  in D-080's "Not checked" (the first shared button would carry the gap into every form).
