**For the builder: what is already there** (checked on `main` at `b156137`)
- **The module** (`src/modules/scheduling/booking.ts`): `createAppointment(tx, booking, now)` locks the
  provider's row (`.for('update')`), checks the treatment, refuses a start the clocks skip, then looks
  for a visit of the provider that holds the chair (`CHAIR_FREED`: cancelled, no-show; `overlap_ok`
  rows count) and inserts with `overlapOk: false`. The moments stay in SQL (`startsAt`, `endsAt` as
  `sql` fragments): compare a duplicate's start there too, never with a moment parsed in JavaScript.
  `BookingRefusal` and `NewBooking` are exported through `index.ts`.
- **The action** (`src/app/(staff)/calendar/actions.ts`, `bookAppointment`): a refusal is
  `return refuse(code)`, and the wrapper rolls the transaction back (`src/app/_lib/actions.ts`). It
  calls `refresh()` (Next.js 16, `next/cache`) only after a booking: for "the warning then names that
  visit", call it before refusing `overlap` too, and check in the e2e that the refused answer brings
  the day (else say so in the note: a read on use brings it within 30 s of the last).
- **The drawer** (`new-appointment.tsx`): `NewAppointment` gets the calendar's current `view` (each
  read on use and each refresh changes it); `BookingDrawer` gets only `choices`, read when it opens
  and keyed by the opening, so nothing typed resets (D-108). The warning needs the current day: hand
  the drawer the chosen provider's column, `view.open` and `view.closed` as props that change, never
  as a key. `StaffForm` renders its children, then the refusal's message, then the one button: a
  warning as the form's last child sits right above Book. `submitLabel` already changes with the
  choices; `refusals` maps a code to its text (`calendar.booking` in `en.json`).
- **The day** (`day.ts`): each column's `blocks` are `AppointmentBlock` (`from`, `to` in minutes of
  the day on the clinic's clock, `status`, `patient`) and `BreakBlock` (`from`, `to`, `label`); a
  column exists for a provider the filter has off too. The grid takes in every block of the day, so a
  block is cut only at midnight. `view.open` is the day's hours, null when closed; `view.closed` is
  `{ why: 'closed_day', label }` or `{ why: 'no_hours' }`; on a closed day no break is listed. On the
  two days the clocks change a block's minutes are the clock's, not real time: the server's check is
  the one that counts (dental hours never meet 02:00–03:00).
