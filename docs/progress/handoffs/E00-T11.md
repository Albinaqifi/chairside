- **The trap for generics:** `mayCarrySubmitterProps()` runs over `constituents()`, which puts a
  type parameter's constraint in its place before the `Instantiable` branch sees it. So
  `P extends Omit<…>` is read as the `Omit<…>` and passes. My first prototype fell into this (the
  `P extends Omit<…>` shape passed, and the two safe constraints were reported). Split unions
  without replacing type parameters, and look at a type parameter first. `kindOfAction()` uses
  `constituents()` too, and should keep it.
