  `pnpm exec playwright test tests/e2e/provider-breaks.spec.ts --project=chromium` (before: 2 failed, 3 passed;
  after: 5 passed). No product code changed.

  "Break added" toast first (a Radix layer above the dialog, as `booking.spec.ts` `closeToast` describes), so the
  dialog stayed open. New `closeWithEscape` presses Escape, waits for no toast, presses again if still open. Same
  command, same result.
