- **Trap** (a probe of `node_modules/.pnpm/@radix-ui+react-checkbox@1.3.11…/dist/index.mjs` and the
  switch's): inside a form, Radix's Checkbox (1.3.11) and Switch (1.3.7) render a hidden
  `<input type="checkbox" aria-hidden>` with `defaultChecked`, and copy their state into it only
  when the state changes, never on mount. A browser that restores the hidden input leaves it unlike
  the button, and `FormData` reads the hidden one. The form's `autocomplete="off"` stops the
  restore; criterion 3 checks it in Firefox. Every Radix part here renders `type: "button"`.
- Radix's Root props are a button's, `formAction` included: shadcn/ui's `{...props}` onto
  `CheckboxPrimitive.Root` is refused by `chairside/forms-post` (D-084); type them with `Omit<…>`.
- The wrapper turns `FormData` into the input (`src/app/_lib/action-input.ts`): one value as it is,
  several as a list; a checkbox or switch left off sends nothing, so its field is `undefined`.
- `react/jsx-no-literals`: a select's empty choice and any visible text come from `en.json`.
- The demo form (`src/app/(staff)/dev/components/demo-form.tsx`): a note, a code and the `answer`
  radios; its actions (`actions.ts`) parse `demoInput` with Zod; `page.tsx` shows each `src/ui/`
