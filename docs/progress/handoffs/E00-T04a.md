- **Traps**
  - `jsx-a11y`'s recommended set holds `no-autofocus`, and the login form's email field has
    `autoFocus`: drop it (no check reads it), or switch the rule off for that file with a reason.
    Say which in the note.
  - `react/jsx-no-literals` also reports text that is only punctuation, such as the header's
    " · ": put it in the message, or allow it with the rule's `allowedStrings`, named in the note.
  - The page titles are visible text that lint cannot see: `metadata` in `src/app/layout.tsx`,
    the login page and the clinic picker ("Log in · Chairside"). They come from the message file
    too, through `generateMetadata`.
  - shadcn/ui's Button as published is typed `React.ComponentProps<"button"> & VariantProps<…> &
    { asChild?: boolean }` and renders `<Comp {...props} />` with `Comp = asChild ? Slot.Root :
    "button"`. E00-T11's lint refuses it until its props are
    `Omit<React.ComponentProps<"button">, 'formAction' | 'formMethod'> & …`. Its variants
    (`default`, `destructive`, `outline`, `secondary`, `ghost`, `link`) become ours (primary,
    secondary, quiet); its `dark:` classes go (no dark mode).
  - The shadcn/ui CLI writes `components.json`, puts components in `src/components/ui` and `cn()`
    in `src/lib/utils.ts` unless told otherwise: the components go in `src/ui/`, and `cn()` can
    live there too.

    is `src/proxy.ts` (D-067). Its plugin wraps `next.config.ts`, and its request configuration
    returns `en`. Version 4.14.9 lists Next.js 16 among its peer dependencies (npm, 2026-10-05).

    `01-getting-started/11-css.md` (Tailwind, with `tailwindcss` and `@tailwindcss/postcss`),

  - The fonts cover Latin only: a name in Cyrillic shows in the fallback font (question below).
