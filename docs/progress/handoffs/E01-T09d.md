**What I built**

add form's fields in a dialog, filled with the provider, inactive ones too. For a provider a login is
linked to (a membership of the clinic, active or disabled), the kind select is disabled, a line under it

Make inactive's answer carries the visits ahead, and the row's `onDone` shows "Provider made inactive.
N visit(s) ahead stay(s) booked with them." in place of the plain toast when N > 0.
