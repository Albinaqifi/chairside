**For the builder: what is already there** (checked on `main` at `d464b7a`)
- `src/app/(staff)/layout.tsx`: a plain header with inline `style` attributes, the clinic's name,
  `staffHeader.signedInAs`, "Switch clinic" when `staff.clinicCount > 1`, `<LogoutButton />`. A
  layout does not re-render on navigation (its own comment), so the marked item comes from a client
  component with `usePathname()` (`node_modules/next/dist/docs/01-app/03-api-reference/02-components/link.md`,
  "Checking active links"). Keep `<Link>`'s default prefetch: `prefetch={true}` renders a dynamic
  page before any click (Discovered, E00-T03 review).
- `currentStaff()` (`src/app/_lib/auth.ts`) gives `user`, `clinic` (a `ClinicChoice`: clinic id
  and name, role, extra permissions, no provider) and `clinicCount`. `can(role, extras, permission)`
  comes from `@/modules/auth`; `allowed()` in `src/app/_lib/actions.ts` builds the same extras, with
  `providerKind: null`. Leave `actions.ts`, `auth.ts`, `src/modules/auth` and `src/proxy.ts` as they
  are: they are critical areas (`test-strategy.md`), and the task needs no change there.
- `src/app/globals.css`: Tailwind's own colours, fonts, text sizes and radii are off, so a class
  outside the tokens gives no style and no error. The demo's sidebar uses three colours the theme
  lacks: item text `oklch(0.35 0.02 210)`, active text `oklch(0.25 0.05 195)`, hover
  `oklch(0.94 0.018 190)` (demo line 33, logic 1778); the active background is `primary-soft`.
  Spacing is Tailwind's own scale: `w-57` is 228 px.
- `src/ui/cn.ts` names our sizes, radii, tracking and animation for tailwind-merge; a token of those
  kinds missing there makes `cn('text-muted', 'text-<new>')` drop the colour, with no error
  (`cn.test.ts`; E00-T04a review suggestion 2).
- `src/ui/button.tsx` draws its focus as an outline (`outline-solid`), which Windows' contrast
  themes keep; `src/ui/input.tsx` uses a ring, which they drop (E00-T04a review suggestion 3,
  struck as `none`). The sidebar's links follow Button. `src/ui/logo.tsx` is the mark and the
  wordmark, as the sidebar header needs them.
- `src/i18n/en.json` holds `staffHeader`, `today`, `logout` and `roles`; lint fails on text in JSX,
  and `en.test.ts` checks that every role has a name and every message formats.
- Fonts: `src/ui/fonts.ts` (`localFont`, the variables `--font-figtree` and `--font-newsreader`)
  feeds `--font-sans` and `--font-serif` in `globals.css` and is set on `<html>` in
  `src/app/layout.tsx`. Onest: github.com/simpals/onest, release 2.001's zip,
  `fonts/webfonts/Onest[wght].woff2` (84 KB) and `OFL.txt`. Source Serif 4:
  github.com/adobe-fonts/source-serif at `80d3f88` (branch `release`),
  `WOFF2/VAR/SourceSerif4Variable-Roman.ttf.woff2` (429 KB) and `LICENSE.md`: its static files have
  no Medium, and the wordmark is 500. Record source and commit in `fonts.ts`, as E00-T04a did.
