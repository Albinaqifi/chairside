**What I built**

**For the tester: look hard at**
- **The hand-written SQL in `src/db/migrations/0000_init.sql`:** `current_clinic_id()`, where
  `nullif` handles the empty-string case, the two `FOR ALL` policies, and the grants.
- **Breaking isolation:** `withTenant` with another clinic's id, `RESET ALL` or
  `SET row_security` inside `fn`, savepoints, nested `withTenant`. A nested call opens a
  separate transaction on another connection.
- **`src/db/reset.ts` guards:** a non-local host, `NODE_ENV=production`, and a `DATABASE_URL`
  user other than `chairside_app` must all be refused.
- **Logger:** shapes not covered by tests (Map, class instances, Buffer), and field names the
  list might still miss.
- **Windows:** run the scripts from Command Prompt as well as PowerShell.
